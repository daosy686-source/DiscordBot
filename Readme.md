📌 GIỚI THIỆU
Nuke Bot là bot Discord quản trị tối cao với hàng loạt tính năng mạnh mẽ, bao gồm khả năng Nuke server, quản trị thành viên, hệ thống level, spam, và nhiều tính năng khác.

✨ TÍNH NĂNG NỔI BẬT
Tính năng	Mô tả
💀 Nuke System	Phá hủy server, xóa kênh/role, ban all, spam tin nhắn
👑 Quản trị tối cao	Kick, Ban, Mute, Warn, Clear, Slowmode, Lock/Unlock
🎭 Role Management	Tạo role, thêm/xóa role cho thành viên
📁 Channel Management	Tạo/xóa kênh, ẩn/hiện kênh, tạo voice channel
📊 Level System	Hệ thống level tự động, gán role theo level
💀 Spam System	Spam chửi, spam @everyone, spam kênh/role
🔒 Anti System	Anti-Nuke, Anti-Raid, Anti-Bot (có cấu hình)
📋 Log System	Log toàn bộ sự kiện server
🎫 Ticket System	Hệ thống ticket hỗ trợ
🛡️ Whitelist	Bảo vệ server khỏi bị nuke
🚀 LỆNH CHI TIẾT
💀 NUKE COMMANDS
Lệnh	Mô tả	Quyền
nuked setup	Hiển thị bảng điều khiển	Owner
nuked nuke	Nuke server (gửi xác nhận qua DM)	Owner
nuked kickall	Kick toàn bộ thành viên	Owner
nuked deleteallchannels	Xóa tất cả kênh	Owner
nuked deleteallroles	Xóa tất cả role	Owner
nuked spamchannels	Tạo hàng loạt kênh spam	Owner
nuked spamroles	Tạo hàng loạt role spam	Owner
nuked spameveryone	Spam @everyone	Owner
👑 MODERATION
Lệnh	Mô tả	Quyền

nuked unban <id>	Unban thành viên	Owner

nuked lock #kênh	Khóa kênh	Owner
nuked unlock #kênh	Mở khóa kênh	Owner

Yêu cầu
Python 3.10+

Discord Bot Token

Railway / VPS / Replit

1. Clone repository
bash
git clone https://github.com/your-repo/nuke-bot.git
cd nuke-bot
2. Cài đặt thư viện
bash
pip install -r requirements.txt
3. Cấu hình
Tạo file .env hoặc set biến môi trường:

env
TOKEN=your_bot_token_here
4. Chạy bot
bash
python bot.py
