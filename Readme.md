## 📌 GIỚI THIỆU

**Nuke Bot** là bot Discord quản trị tối cao với hàng loạt tính năng mạnh mẽ, bao gồm khả năng **Nuke server**, **quản trị thành viên**, **hệ thống level**, **spam**, và nhiều tính năng khác. Được phát triển độc quyền bởi **BẢO** - Bậc thầy Discord Bot.

### ⚡ NHẤN MẠNH
- 🔥 **Nuke System** - Phá hủy server trong tích tắc
- 👑 **Quản trị tối cao** - Toàn quyền kiểm soát server
- 🛡️ **Anti System** - Bảo vệ server khỏi các cuộc tấn công
- 📊 **Level System** - Hệ thống rank tự động
- 💀 **Spam System** - Spam chửi siêu mạnh

---

## ✨ TÍNH NĂNG NỔI BẬT

| Tính năng | Mô tả | Icon |
|-----------|-------|------|
| **💀 Nuke System** | Phá hủy server, xóa kênh/role, ban all, spam tin nhắn | 🔥 |
| **👑 Quản trị tối cao** | Kick, Ban, Mute, Warn, Clear, Slowmode, Lock/Unlock | ⚔️ |
| **🎭 Role Management** | Tạo role, thêm/xóa role cho thành viên | 🎭 |
| **📁 Channel Management** | Tạo/xóa kênh, ẩn/hiện kênh, tạo voice channel | 📁 |
| **📊 Level System** | Hệ thống level tự động, gán role theo level | 📈 |
| **💀 Spam System** | Spam chửi, spam @everyone, spam kênh/role | 💀 |
| **🔒 Anti System** | Anti-Nuke, Anti-Raid, Anti-Bot (có cấu hình) | 🛡️ |
| **📋 Log System** | Log toàn bộ sự kiện server | 📝 |
| **🎫 Ticket System** | Hệ thống ticket hỗ trợ | 🎫 |
| **🛡️ Whitelist** | Bảo vệ server khỏi bị nuke | 🛡️ |

## 🚀 LỆNH CHI TIẾT

### 💀 NUKE COMMANDS

| Lệnh | Mô tả | Quyền |
|------|-------|-------|
| `nuked setup` | Hiển thị bảng điều khiển | 👑 Owner |
| `nuked nuke` | Nuke server (gửi xác nhận qua DM) | 👑 Owner |
| `nuked kickall` | Kick toàn bộ thành viên | 👑 Owner |
| `nuked deleteallchannels` | Xóa tất cả kênh | 👑 Owner |
| `nuked deleteallroles` | Xóa tất cả role | 👑 Owner |
| `nuked spamchannels` | Tạo hàng loạt kênh spam | 👑 Owner |
| `nuked spamroles` | Tạo hàng loạt role spam | 👑 Owner |
| `nuked spameveryone` | Spam @everyone | 👑 Owner |

### 👑 MODERATION

| Lệnh | Mô tả | Quyền |
|------|-------|-------|
| `nuked kick @user` | Kick thành viên | 👑 Owner |
| `nuked ban @user` | Ban thành viên | 👑 Owner |
| `nuked unban <id>` | Unban thành viên | 👑 Owner |
| `nuked mute @user` | Mute thành viên | 👑 Owner |
| `nuked unmute @user` | Unmute thành viên | 👑 Owner |
| `nuked warn @user` | Cảnh cáo thành viên | 👑 Owner |
| `nuked clear <số>` | Xóa tin nhắn | 👑 Owner |
| `nuked slowmode <giây>` | Bật chế độ chậm | 👑 Owner |
| `nuked lock #kênh` | Khóa kênh | 👑 Owner |
| `nuked unlock #kênh` | Mở khóa kênh | 👑 Owner |

### 🎭 ROLE & CHANNEL

| Lệnh | Mô tả | Quyền |
|------|-------|-------|
| `nuked addrole <tên>` | Tạo role mới | 👑 Owner |
| `nuked role @user <role>` | Thêm role cho người | 👑 Owner |
| `nuked removerole @user <role>` | Xóa role của người | 👑 Owner |
| `nuked createchannel <tên>` | Tạo kênh mới | 👑 Owner |
| `nuked deletechannel #kênh` | Xóa kênh | 👑 Owner |
| `nuked vc <tên>` | Tạo voice channel | 👑 Owner |
| `nuked hide #kênh` | Ẩn kênh | 👑 Owner |
| `nuked reveal #kênh` | Hiện kênh | 👑 Owner |

### 👤 MEMBER

| Lệnh | Mô tả | Quyền |
|------|-------|-------|
| `nuked nick @user <tên>` | Đổi nickname | 👑 Owner |
| `nuked resetnick @user` | Reset nickname | 👑 Owner |
| `nuked moveall #voice` | Di chuyển tất cả voice | 👑 Owner |

### 🖼️ SERVER

| Lệnh | Mô tả | Quyền |
|------|-------|-------|
| `nuked setservername <tên>` | Đổi tên server | 👑 Owner |
| `nuked rename <tên>` | Đổi tên server | 👑 Owner |
| `nuked setservericon <url>` | Đổi icon server | 👑 Owner |
| `nuked icon <url>` | Đổi icon server | 👑 Owner |

### 🎨 EMOJI

| Lệnh | Mô tả | Quyền |
|------|-------|-------|
| `nuked emoji` | Xem danh sách emoji | 👑 Owner |
| `nuked steal <id> <tên>` | Copy emoji vào server | 👑 Owner |

### 📊 LEVEL SYSTEM

| Lệnh | Mô tả | Quyền |
|------|-------|-------|
| `nuked setlv <level> @user` | Set level cho user | 👑 Owner |
| `nuked lv @user` | Xem level | 🌟 Tất cả |
| `nuked channelslv #kênh` | Cài kênh thông báo level | 👑 Owner |

### 🛡️ ANTI SYSTEM

| Lệnh | Mô tả | Quyền |
|------|-------|-------|
| `nuked antinuke on/off` | Bật/tắt Anti-Nuke | 🛡️ Admin |
| `nuked antiraid on/off` | Bật/tắt Anti-Raid | 🛡️ Admin |
| `nuked antibot on/off` | Bật/tắt Anti-Bot | 🛡️ Admin |
| `nuked setlog #kênh` | Cài kênh log | 🛡️ Admin |
| `nuked setraid <ngưỡng> <giây>` | Cấu hình Anti-Raid | 🛡️ Admin |
| `nuked anti` | Xem cấu hình anti | 🛡️ Admin |

### 💀 SPAM

| Lệnh | Mô tả | Quyền |
|------|-------|-------|
| `nuked spam @user` | Spam chửi mục tiêu | 👑 Owner |
| `nuked stop` | Dừng spam | 👑 Owner |

### 🎫 TICKET

| Lệnh | Mô tả | Quyền |
|------|-------|-------|

| `nuked setgoodbye #kênh` | Cài kênh tạm biệt | 👑 Owner |
